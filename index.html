ABOUT

Building worlds, one system at a time.

I'm a self-taught developer who started with Python and never really stopped building. What began as small scripts turned into a habit of shipping finished, playable things — games built in Pygame, tools written in C++, and whatever else a project needed.

Game development is where most of that energy goes: gameplay systems, procedural generation, and the kind of graphics programming and OpenGL experiments that turn math into something you can watch move on screen. I care just as much about the layer underneath — clean UI systems and software engineering habits that let a small project grow without falling apart.

I'm starting Information Technology at IIIT Allahabad this year, and I'm bringing that same instinct with me: build it, break it, understand why, build it better.
